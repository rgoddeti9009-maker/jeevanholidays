# Jeevan Holidays Shirdi — AI Kiosk & Mobile Booking

One app for the office touchscreen kiosk (`/kiosk`) and customers' phones (`/`): book cabs, sightseeing, tour packages, airport/railway transfers, with an AI + voice assistant in English, हिंदी, मराठी and తెలుగు.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, Web Speech API, `qrcode`, Netlify (Image CDN; Database/Identity/AI Gateway next).

**Run locally:** `pnpm install` then `netlify dev` (or `pnpm dev`).

**Roadmap:** see [PLAN.md](PLAN.md) — database, admin CRM, hosted AI, payments and WhatsApp API come next.
